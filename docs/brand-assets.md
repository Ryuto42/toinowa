# ロゴ・アイコン

2026-09-22にユーザー提供の2枚を採用。ロゴの形・配色は変更せず、用途に合わせたサイズ・形式に変換した。

| 用途 | ファイル | 元画像 |
| --- | --- | --- |
| サイト内（トップ、ログイン、各ロールのナビゲーション） | `public/brand/logo.png`（256px） | 透過版 `(1).png` |
| ブラウザタブ | `src/app/favicon.ico`（16/32/48px）、`src/app/icon.png`（48px） | 透過版 |
| iPhone・iPadのホーム画面 | `src/app/apple-icon.png`（180px） | 白背景版 `(2).png` |
| PWAホーム画面・通知 | `public/brand/icon-192.png`、`icon-512.png` | 白背景版 |

元ファイル名は `ChatGPT Image 2026年9月22日 00_03_10 (1).png` と同名の `(2).png`。白背景版は透過に対応しないホーム画面でも背景を保てる。PWAはロゴが切り抜かれないよう通常アイコンとして指定し、マスク用アイコンとしては宣言していない。

画面内は共通の `src/components/brand-mark.tsx` を利用。隣接するサービス名と読み上げが重複しないよう、ロゴ画像自体は装飾画像にしている。サービス名は既存の `BRAND` 設定を引き続き参照する。

favicon・Apple用アイコンはNext.jsのファイル規約で登録し、PWA用は `src/app/manifest.ts`、通知用は `public/sw.js` で参照する。ブラウザや既に追加済みのホーム画面で旧アイコンが残る場合は、再読み込みまたはホーム画面への追加し直しが必要な場合がある。
