# 2026-09-21 改善と検証記録

目的はAI HACK 2026で勝つこと。テーマは「業務を自律化するAIエージェント」。審査はセキュリティ、コストパフォーマンス、信頼性・堅牢性、自律性、アイデア・独創性の5項目、各10点。
提供PDFとガイダンスの要点、提出条件、OrcaRouter賞5万円の訂正は [hackathon.md](hackathon.md) を参照。
先生が宿題の対象と期限を決めて配信する運用を維持する。生徒へ次々と自動配信しない。

## OrcaRouterの費用について

ユーザー申告：20 USDのクレジットに対して使用済み約0.108844 USD。差額は **19.891156 USD**（2026-09-21の申告に基づく計算。ライブ残高ではない）。
この改善の検証では実モデルを呼ばず、モック応答またはAI予算0の一時所属を使う。
残高を画面へ固定表示したり、今回の検証で請求額が不変だったと断定したりしない。他の利用や請求反映の遅延は別に存在し得る。

予算チェックは所属単位の日次台帳に基づく。複数の同時実行を予約額で抑える仕組みではなく、アカウント全体の20 USDを厳密に保護するものでもない。
未取得の費用、タイムアウト中の上流課金、台帳反映前の並列リクエストには限界がある。モデル別表示の費用は一連の試行の合計で、モデル名は最終応答の解決先。

## 4分の説明で強調する点

「AIに教えるチャット」だけでなく、**先生が授業記録を渡す → 生徒に合った宿題候補 → 先生の配信判断 → 生徒の説明 → 根拠つき分析 → 次回の指導案**という仕事の一連の流れを見せる。

- 0:00–0:35：先生の宿題準備・個別理解度確認の課題と、どの業務を任せるか。
- 0:35–1:25：教材と生徒情報から個別候補。先生が期限を決めて配信する承認点。
- 1:25–2:15：生徒が説明し、AIが不明点を選んで聞く。生徒の評価は終了後の簡易版。
- 2:15–3:00：根拠発言から先生が確認・修正。その判断が次回計画に反映される流れ。
- 3:00–3:40：出力遮断・障害復旧の自動テスト結果と、観測した費用・費用不明の区別。
- 3:40–4:00：解決する課題と効果、残る検証を端的に述べる。

実モデルの停止を再現したと称してモックテストを見せない。「障害を模した自動テスト」と明示する。
自律的な外部ツールの任意選択や未測定の削減率は主張しない。

## 受賞に向けて、実装だけで埋まらない残りの課題

1. 先生が同じ教材で手作業する時間と、本サービスで確認・配信する時間を実測する。架空の削減率を示さない。
2. 実際の教科・学年・誤答例を先生が評価したデータで、質問とフィードバックの品質を測る。既存の2例のモデル比較だけで一般化しない。
3. 新しい対話プロンプトの教育的な質は、今回の課金なし検証では確定していない。必要な少数例で教師確認付き評価を行う余地がある。
4. 未知の間接インジェクション、OrcaRouter側のGuardrails設定、本番workerの定期到達性は引き続き実環境の確認が必要。
5. 提出用記事・公開ソース・4分発表の準備を完了する。提出や外部公開は今回実施していない。
