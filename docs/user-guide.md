# StudyPilot 使い方ガイド

先生が授業で教えた内容を、生徒が「自分の言葉で説明できる理解」へつなげるサービスです。ファインマンテクニックに着想を得ています。

先生は授業と教育上の判断に集中し、AIは復習課題の設計、説明対話、理解の分析、次の学習計画の提案を担当します。考えて説明するのは生徒です。

## 全体の流れ

1. 管理者が先生・生徒を登録し、担当を設定する。クラスは集合授業で必要なときだけ作る。
2. 先生が授業メモや資料を渡す。
3. AIが模試・過去の説明・フィードバックも参考に、生徒別の課題と学習計画を準備する。
4. 先生が内容と理由を確認し、必要なら編集して承認・配信する。
5. 生徒がAIに教えるように説明し、質問に答えながら考えを整理する。
6. 対話終了後にAIが分析し、次の計画と課題案を更新する。次回の配信も先生が判断する。

**計画の更新だけで課題が次々に配信されることはありません。** 計画の詳細は先生向けです。生徒には先生が配信したお題を表示します。

## 先生：普段の操作は「渡す」「確認する」

### 1. 今日の授業を渡す

「授業と宿題」を開き、「今日の授業をAIに渡す」で次を入力します。

| 項目 | 入れる内容 |
| --- | --- |
| 対象生徒またはクラス（必須） | 個別指導なら「生徒を選ぶ」、集合授業なら「クラスを選ぶ」 |
| 宿題の期限（必須） | 生徒に取り組んでほしい期限 |
| 授業メモまたは資料（どちらか必須） | 扱ったテーマ・具体例・まだ教えていない範囲。PDFや写真も使えます |
| 授業の名前（任意） | 未入力なら記録の冒頭が名前になります |

例えば、次の授業メモだけでも始められます。

> 今日は一次関数の傾きと切片を学習。式からグラフを描く練習をした。傾きが「横に1進むときの縦の変化」であることを説明した。文章題はまだ扱っていない。

お題の文面、難易度、評価基準を先生が設計する必要はありません。

資料は選択すると自動で読み取ります。読み取り完了までは画面を開いておいてください。「読み取った授業資料を確認・修正」で内容を見直せます。

**「授業記録を渡して、課題の準備を任せる」** を押し、受付完了が表示されたら別の画面へ移動できます。選んだ生徒、またはクラスの在籍生徒ごとに準備が進みます。人数やAIの応答によって時間がかかり、一人ずつ結果が届きます。

### 2. 生徒別の課題を確認する

「先生の確認待ち」で、次を確認します。

- 説明してもらうお題が授業範囲に合っているか。
- 「この課題を選んだ理由・計画の変更」に納得できるか。
- 学習時間の目安と期限が適切か。
- 黄色い注意点がある場合、履歴不足や時間の仮設定などを確認したか。

同じ授業でも、過去の説明や模試に応じて意味の説明を優先したり、具体例を求めたりする案を作ります。履歴がない場合は、初回の課題として確認してください。

必要な課題だけ「確認・編集」でお題・難易度・期限・参考内容を直せます。「下書きのまま保存」すれば生徒には配信されません。

問題のない課題の **「内容・期限を確認しました」** にチェックし、**「確認した○件を承認して配信」** を押します。一件だけの配信もできます。確認後に別の先生が編集した課題は、画面を更新して再確認してください。

### 3. 生徒の説明と、計画の変化を見る

「生徒」から対象の生徒を開きます。

- 「提出ごとの分析」：説明の根拠、良かった点、確認が必要な点。
- 「学習計画と変更理由」：次に何を学ぶか、なぜその順番か。評価後の更新では、根拠となった説明・評価を開けます。
- 「過去の提案・他クラスの計画を見る」：以前の提案との比較。

AIの評価が違うと感じたときは、分析画面で根拠を確認し、必要に応じて修正してください。先生の修正を次の提案で優先します。

### 特定のお題を指定したいとき

通常は授業記録からの準備を使います。特定のテーマや文面を指定したい場合は、画面下の「特定のテーマ・お題を指定したいとき」を開きます。テーマ・学んだ内容からAIに考えさせることも、「お題を直接指定する」で問題文を指定することもできます。

### 準備が失敗したとき

一時的な障害は自動で再試行します。失敗が確定した生徒分は、準備状況の「失敗した生徒分を再試行」から再開できます。成功した課題は残り、保存済みの計画も再利用します。

予算超過や資料の問題は、管理者と原因を確認してから再試行してください。授業記録そのものを新しく送ると、成功済みの生徒も新しい生成の対象になります。

## 生徒：AIに教えてみよう

初めての方は「今日の学習」または「AIワーク」の **「AIと話す練習をする」** を開きます。好きなことを自己紹介がわりに伝える固定の案内から始まり、送信後はAIが内容に合わせて短い質問を返します。話題は好きなことから、得意・苦手な勉強や今後できるようになりたいことへ自然につながります。回数は固定せず、AIが内容をまとめて生徒の意向を確認してから区切ります。「今回はここまで」で自分から終了することもできます。答えたくない項目を埋める必要はなく、宿題の理解度評価や学習計画には混ぜません。先生の承認を必要としない使い方の練習です。途中で離れても続きから再開できます。

チャットでは会話部分だけがスクロールし、入力欄と送信ボタンは画面下に残ります。画面上部の「AIワークへ」で一覧へ戻れます。送信ボタンかEnterで送信、Shift+Enterで改行します。

1. 所属コード・ログインID・初期パスワードでログインする。初回は自分のパスワードへ変更する。
2. 「今日の学習」または「AIワーク」から先生の課題を開く。
3. AIに、言葉の意味や理由を説明する。身近な例も使ってみる。
4. 質問されたら、説明を言い直したり、例を変えたりする。わからないときは、そのまま伝えてよい。
5. 対話終了後、分析が完了したら「フィードバック」で良かった点と次の一歩を見る。

長い文章を書くことや、AIの説明を写すことが目的ではありません。自分の言葉で伝えることを大切にします。対話の途中ではフィードバックを表示しません。

お題がない場合は、先生の配信を待ちます。パスワードを忘れた場合は、先生や管理者に連絡してください。

## 管理者：最初の準備と継続運用

### アカウントとクラスを用意する

「ユーザー管理」で先生を登録し、生徒の登録画面で「担当の先生」を選びます。クラスなしの個別指導に対応しています。既存の生徒は「編集」→「個別指導の担当の先生」から設定できます。複数の先生を選択できます。

集合授業で一括して授業記録を渡したい場合は、「クラス管理」でクラスと担当の先生・在籍生徒を設定します。個別指導との併用もできます。生徒のメールアドレスは不要です。担当とクラスは任意ですが、先生の画面に表示するにはどちらかの担当設定が必要です。

生徒のログインIDは所属ごとに `student1`、`student2`… と自動発行します。入力は不要です。既存の番号の続きから発行し、削除した番号は再利用しません。既存ユーザーのIDは変更しません。

登録画面の「必須」の印がある項目を入力します。利用目的・目標、苦手範囲、模試結果、1日の学習時間は任意です。

全ロールで初期パスワードを自動生成します。登録後のポップアップで **「ログイン情報をコピー」** を押し、所属コード・ログインIDまたはメールアドレス・初期パスワードを本人に伝えます。初回ログイン後は変更が必要です。

所属コードはログイン画面でブラウザへの保存を選択できます。

### 模試結果を追加する

登録時だけでなく、既存の生徒の編集画面でもPDFや写真を追加できます。選ぶと自動分析が始まり、読み取った結果から目標・苦手範囲・学習時間を提案します。

アップロード完了後は、分析中でも登録や別の操作ができます。完了すると反映されます。分析中に手動で変えた項目は保持します。提案された目標や時間は本人の希望を確定したものではないので、必要に応じて編集してください。

模試の分析結果を反映した後、所属クラスごとの計画更新も予約します。

### パスワードをリセットする

ユーザーの編集画面で初期パスワードを再発行します。コピーして本人へ伝え、再ログイン後に変更してもらいます。以前の初期パスワードの再表示はできません。

### AIの利用を確認する

「AI利用状況」で、誰が・どの機能で・どのモデルを・どの程度使ったかを確認します。予算上限に達した場合はAI処理が止まるため、失敗を繰り返し再試行する前に利用状況を確認してください。

## 資料と分析に関する補足

- PDFは8ページ以内、画像はJPEG・PNG・WebP、ファイルは15MB以内です。大きな資料は分けてください。
- 不要な氏名・連絡先を除き、文字が鮮明な写真を使ってください。
- 授業資料の読み取り中は画面を開いておきます。受付後の生徒別課題準備はバックグラウンドで続きます。
- 模試もファイル送信が終わる前にブラウザを閉じると続行できません。バックグラウンド分析中の表示を確認してください。
- 理解度は、その説明から観測できた範囲の評価です。一度の会話で学力全体を断定するものではありません。
- 計画の学習時間が未設定の場合、1日30分を上限にした仮の提案となり、先生へ注意点を表示します。

画面右上の「使い方ガイド」から、そのロール向けの説明をいつでも開けます。

### 生徒・クラスのアーカイブと完全削除

- 生徒は「ユーザー管理」→「編集」→「アーカイブする」。ログインと新しい学習を停止します。
- クラスは「クラス管理」→対象の「アーカイブする」。そのクラスの新しい課題作成・配信・対話を停止します。在籍者の別クラス・個別指導の利用は継続できます。
- 履歴は保持します。一覧の「アーカイブ済みも表示」を選び、「復元する」で再開できます。停止されたAI作業は自動再開しません。必要な授業記録を再度渡してください。
- 完全削除はアーカイブ後のみ可能です。削除対象の件数を確認し、対象名を入力して実行します。実行中のAI処理がある場合は完了まで待ち、関連データが変わった場合は再確認します。
- 生徒の完全削除は認証アカウント・模試・個別学習履歴も対象です。クラスの完全削除はそのクラスの履歴が対象で、生徒・先生のアカウントは削除しません。
- 操作監査と所属全体の費用集計は残します。共有の授業メモ内の記載は自動では書き換えません。完全削除は元に戻せません。

個別指導は内部では生徒専用の学習領域を自動作成し、既存の権限制御・課題・対話・計画の仕組みを共有しています。管理者が通常のクラスとして管理する必要はありません。

学年と名前だけなど、学習範囲を決める情報がない登録では、AIに自己紹介のお題や学習計画を推測させません。自己紹介は上記の練習で扱い、学習の課題案は模試・目標・苦手範囲や先生の授業記録が入ってから準備します。未入力の生徒の自己紹介・学習目標の聞き取りはチュートリアルにまとめ、学習課題としては作りません。
